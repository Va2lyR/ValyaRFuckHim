# ValyaRFuckHim

A PowerShell GUI toolkit that bundles 100+ open-source forensic, analysis, and screenshare tools into a single launcher.

## Quick Start

Open PowerShell as **Admin** and paste:

```powershell
irm https://raw.githubusercontent.com/Va2lyR/ValyaRFuckHim/main/ValyaRFuckHim.ps1 -OutFile "$env:TEMP\ValyaRFuckHim.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\ValyaRFuckHim.ps1"
```

## Features

- **Mod Analyzers** - Analyze Minecraft mods for cheats and suspicious content
- **Clients Detector** - Detect ghost clients, Doomsday, and other cheat clients
- **Forensics Tools** - Prefetch, BAM, USN Journal, MFT, and more
- **One-click downloads** - Tools are fetched from GitHub on demand
- **Built-in quick access** - Open Prefetch, Temp, Recycle Bin, Crash Dumps, etc.

## Requirements

- Windows 10/11
- PowerShell 5.1+
- Administrator privileges (auto-elevates)

## Disclaimer

Every tool included is open-source and fetched directly from its original GitHub repository. Use at your own risk.
